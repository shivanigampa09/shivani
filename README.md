# ✨ Shivani Gampa — Developer Portfolio

A modern, high-performance developer portfolio built with **React 19**, **Vite**, and **Tailwind CSS**, featuring 3D physics-based interactions, CRT terminal emulation, cyber-styled continuous tool marquees, and commercial project showcases.

## ✨ Key Features

- **Decrypted Cyber Title & Typewriter**: Real-time matrix text decryption effect and animated role ticker.
- **Interactive 3D ID Lanyard**: Draggable badge with Verlet physics, realistic tension simulation, and holographic sheen.
- **Dual-Marquee Dev Tools Showcase**: High-speed, seamless looping marquee displaying core technologies, live status pills, and CLI command badges (featuring Firebase, Supabase, React, Node, MongoDB, and more).
- **Interactive 3D Storybook**: 3D flip card narrative documenting problem-solving approach and production impact.
- **Commercial Projects Showcase**: Deep-dive modals and live production links for client platforms like **Devshe** (`devshe.in`) and **Hotel Ananda Inn** (`anandainn.com`).
- **Interactive Retro CRT Terminal**: Working command-line prompt supporting commands like `help`, `skills`, `projects`, `contact`, and `clear`.
- **Fluid Custom Cursor & Ambient Mesh**: Magnetic cursor dynamics with aurora lighting effects and particle background.

## 💻 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `yarn`

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/shivanigampa09/portfolio.git
   cd "shivani portfolio"
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Lint the project**:
   ```bash
   npm run lint
   ```
